# Installing CardSnap

CardSnap isn't on the Google Play Store, so you'll install it directly
from the APK file (this is called "sideloading"). It's a normal part of
installing non-Play apps on Android and only takes a minute.

## 1. Download the APK

Download `CardSnap_4Mi.apk` from the Releases page:

**[github.com/bbdvengineering/CardSnap_4Mi/releases](https://github.com/bbdvengineering/CardSnap_4Mi/releases)**

Open the link on your Android phone, or download it on a computer and
transfer the file to your phone (email it to yourself, use Google Drive,
or plug in a USB cable).

## 2. Allow installs from this source

Android blocks installs from outside the Play Store by default. The first
time you try to install the APK, you'll be prompted to allow it:

1. Tap the downloaded APK file.
2. If you see **"For your security, your phone is not allowed to install
   unknown apps from this source,"** tap **Settings** on that prompt.
3. Toggle on **Allow from this source** (the exact wording varies by
   phone - it may say "Install unknown apps" instead).
4. Go back and tap the APK file again.

You only need to do this once per app you install this way.

## 3. Install

Tap **Install**, then **Open** once it finishes.

## 4. Permissions

CardSnap will ask for a couple of permissions the first time you use
certain features:

- **Camera** - needed to scan business cards.
- You may also be prompted the first time you save a scanned card to
  your device's contacts.

You can deny a permission and still use the rest of the app; only the
feature that needs it won't work until you grant it.

## Updating later

New versions will be posted as new releases on the same page. To
update, just download the new APK and install it the same way - it
installs over the existing app and keeps your saved cards.

## Troubleshooting

**"App not installed" error** - You likely have an older version
installed under a different signing key, or storage is full. Try
uninstalling the old version first, then reinstalling.

**Play Protect warning during/after install** - This is expected for
any app installed outside the Play Store. Since this isn't published
on Play, Google can't vouch for it the way it does for Play apps. If
you trust the source you downloaded it from, it's safe to proceed.
